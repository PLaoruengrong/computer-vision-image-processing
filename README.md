# Computer Vision & Image Processing

This repository contains selected computer vision and image processing projects implemented using MATLAB and OpenCV.

The projects focus on classical image analysis pipelines, geometric feature extraction, and camera calibration techniques commonly used in robotics and autonomous systems.

---

# Projects

## 1. Door Gap Detection & Geometric Feature Extraction (MATLAB)

Implemented a classical computer vision pipeline for door-gap segmentation and corner localization.

Features:
- Grayscale preprocessing
- Contrast enhancement
- Sobel edge detection
- Morphological filtering
- Hough transform line extraction
- Corner localization using line intersections

Topics:
- Digital Image Processing
- Feature Extraction
- Geometric Vision

---

## 2. Camera Calibration using OpenCV (C++)

Implemented a checkerboard-based camera calibration pipeline using OpenCV.

Features:
- Chessboard corner extraction
- Subpixel interpolation
- Intrinsic parameter estimation
- Distortion correction
- Reprojection error analysis

Topics:
- Camera Geometry
- Geometric Projection
- Calibration & Rectification
- OpenCV
